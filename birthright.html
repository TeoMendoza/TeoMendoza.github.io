Overview

Birthright is a competitive 1v1 strategy card game built around a constant tug-of-war for advantage. Matches come down to strategy, resource management, and utility usage, as both players trade momentum back and forth trying to outplay each other in a drawn-out war of attrition.

Released on itch.io with 50 players, and selected to present at the Portland Retro Gaming Expo (~30k estimated attendees).

Technical Overview

I developed the backend solo and currently work with a team of two artists. The client is built in Godot (C#). A custom Rust module running on SpacetimeDB owns all game state and turn resolution, so both players stay in sync with the server.

  • Authoritative server: game state and turn resolution live entirely in the Rust module; clients only send actions
  • Hidden information: the server computes a per-connection view of the game, so clients never receive hidden state such as the opponent's hand or enemy data
  • Matchmaking and reconnect / desync recovery are implemented server-side
  • Data-driven content: all game content is defined as data and resolved through enum-based dispatch, so new content needs no code changes
