Pedalogical

AI-powered learning platform for students and instructors

Pedalogical is an NSF-funded educational platform that uses LLMs to give students personalized feedback within instructor-defined limits. It ran in a Spring 2026 university study with 150 students and has since been taken down, as it was built for the study.

Tech: ASP.NET · EF Core · PostgreSQL · LLM APIs · CI/CD

Paper

Mendoza, T., et al. (2025). Not All Chatbots Teach: Evidence for Pedagogical Design in AI-Assisted Technical Education. ACM SIGCITE 2025.

The paper reports on the Spring 2025 study, which ran on an earlier prototype backend I built as a research assistant.

My Role: Project Manager & Backend Developer

  • Led a three-person student team on an NSF-funded initiative, running Agile sprints and milestones and acting as liaison to the faculty project lead
  • Wrote 80% of the code for the Spring 2026 version (ASP.NET, EF Core, PostgreSQL)
  • Designed an LLM feedback pipeline that builds rolling student profiles (behavior, strengths, weaknesses) during interactions and periodically re-evaluates and prunes them. This replaced full student-history prompts, keeping feedback consistent over long interactions instead of degrading, and cut tokens per call by an estimated 25%
  • Championed and oversaw a CI/CD pipeline with unit tests that gates production releases on a passing build
  • Oversaw system redesigns for classroom-scale deployment
