Pedalogical

Full-stack learning platform for students and instructors

Pedalogical is an NSF-funded educational platform that gives students personalized, AI-assisted feedback within limits set by their instructor. It ran in a Spring 2026 university study with 150 students and has since been taken down, as it was built for the study.

Tech: ASP.NET · EF Core · PostgreSQL · CI/CD · LLM APIs

My Role: Project Manager & Lead Developer

  • Led a three-person student team on an NSF-funded initiative, running Agile sprints and milestones and acting as liaison to the faculty project lead
  • Oversaw backend and database design, including redesigns for classroom-scale deployment
  • Wrote 80% of the code for the Spring 2026 version, including the ASP.NET backend and the PostgreSQL data layer (EF Core)
  • Championed and oversaw a CI/CD pipeline with unit tests that gates production releases on a passing build
  • Designed the feedback system around rolling student profiles instead of full student histories, keeping feedback consistent over long interactions and cutting LLM tokens per call by an estimated 25%

Paper
